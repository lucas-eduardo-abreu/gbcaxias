# gbcaxias

Marketing website for Gracie Barra Caxias do Sul, a Brazilian Jiu-Jitsu academy
in Caxias do Sul, Rio Grande do Sul. Single-page static site — no frameworks,
no build step, no external dependencies beyond Google Fonts.

## Stack

- Vanilla HTML5 · CSS3 · JavaScript (ES6+)
- Google Fonts (Bebas Neue, Cinzel, Barlow)
- Google Maps embed

## Sections

- **Hero** — animated headline with staggered text reveal
- **About** — academy overview and philosophy
- **Programs** — six program cards covering all age groups and skill levels (GB1, GB2, GB3, Kids, Special, No-Gi)
- **Schedule** — color-coded weekly class timetable rendered with CSS Grid
- **Location** — embedded Google Maps with address
- **CTAs** — WhatsApp links pre-populated with contact messages

## Features

- Custom animated dual-ring cursor
- Intersection Observer scroll-reveal animations
- Responsive hamburger navigation with full-screen overlay
- SEO metadata and JSON-LD structured data
- Accessible: skip-to-content link, semantic landmarks, ARIA labels

## Running

Open `index.html` in any modern browser. No server or dependencies required.
